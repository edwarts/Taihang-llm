# Taihang-llm
LLM based code for Taihang project , support quant trading using LLM

![Taihang](https://kpwhbjb.cgl.org.cn/article/2023/2096-9791/2096-9791-34-1-30/thumbnail/img_1.jpg)

This project uses LLMs to power a quantitative trading platform. It includes scripts for backtesting, pipeline execution, and API testing.
